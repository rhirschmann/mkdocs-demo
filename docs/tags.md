# Tags

Op deze pagina vind je een automatisch gegenereerd overzicht van alle tags
die in deze documentatie worden gebruikt. Klik op een tag om alle pagina's
te zien die aan die tag gekoppeld zijn.

!!! tip "Tags toevoegen"
    Voeg tags toe aan een pagina via de frontmatter bovenaan je Markdown-bestand:

    ```yaml
    ---
    tags:
      - jouw-tag
      - nog-een-tag
    ---
    ```
