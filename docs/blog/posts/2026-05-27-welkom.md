# Welkom bij de mkdocs-demo blog!

MkDocs Material heeft een ingebouwde blogfunctie — en deze post is daar het bewijs van. Geen externe plugin, geen extra configuratie: gewoon een map `blog/posts/` aanmaken en schrijven.

<!-- more -->

## Wat kan de blog plugin?

De blog plugin van MkDocs Material genereert automatisch een aantal handige functies op basis van je posts.

- **Archief** — automatisch gegroepeerd op jaar en maand
- **Categorieën** — overzichtspagina per categorie
- **Tags** — geïntegreerd met de tags plugin
- **Leestijd** — automatisch berekend op basis van het aantal woorden
- **Auteursprofiel** — naam, beschrijving en avatar via `.authors.yml`

## Hoe werkt het?

Een blogpost is een gewoon Markdown-bestand in de map `docs/blog/posts/`. De bestandsnaam bepaalt de datum en de slug van de URL:

docs/blog/posts/2026-05-27-welkom.md → /blog/2026/05/27/welkom/
