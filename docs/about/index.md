# Over dit project

Dit project is een demonstratie van hoe eenvoudig je met **MkDocs** en **GitHub Actions**
professionele documentatie publiceert — volledig geautomatiseerd en gratis.

## Gedemonstreerde features

- **Admonitions** — note, tip, warning, danger, success, info en collapsible blokken
- **Code blokken** — syntaxkleuring, regelnummers en kopieerknop
- **Content Tabs** — gerelateerde inhoud naast elkaar in tabbladen
- **Grids & Cards** — visuele kaartweergave voor navigatie en overzichten
- **Mermaid diagrammen** — flowcharts, sequentie- en statusdiagrammen
- **Tags** — categorisering van pagina's via frontmatter
- **Afkortingen** — automatische tooltips via een gedeeld snippetbestand
- **Takenlijsten** — visueel gestylede checkboxen
- **Footnotes** — voetnoten voor bronvermeldingen
- **Iconen & Emoji** — Material Design, FontAwesome en Octicons
- **Knoppen** — primaire en secundaire call-to-action knoppen
- **Blog** — ingebouwde blogfunctionaliteit met auteurspagina's
- **404-pagina** — aangepaste foutpagina zichtbaar via de navigatie

## Gebruikte technologieën

- [MkDocs](https://www.mkdocs.org/) — statische sitegenerator voor documentatie
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) — thema met uitgebreide opmaakopties
- [GitHub Actions](https://docs.github.com/en/actions) — CI/CD voor automatische deployment
- [GitHub Pages](https://pages.github.com/) — gratis hosting van statische sites
