# Welkom bij mkdocs-demo 👋

Een moderne, snelle en overzichtelijke documentatiesite gebouwd met **MkDocs** en het **Material**-thema — zonder dat je één regel HTML of CSS hoeft te schrijven.

---

## Wat kun je hier leren?

Deze site demonstreert hoe eenvoudig je professionele documentatie publiceert via GitHub. Alles wat je ziet — navigatie, zoekfunctie, donker/licht thema, codeblokken — wordt automatisch gegenereerd uit gewone Markdown-bestanden.
