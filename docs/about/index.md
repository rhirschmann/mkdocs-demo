# Over dit project

Dit project is een demonstratie van hoe eenvoudig je met **MkDocs** en **GitHub Actions**
professionele documentatie publiceert — volledig geautomatiseerd en gratis.

## Gebruikte technologieën

- [MkDocs](https://www.mkdocs.org/) — statische sitegenerator voor documentatie
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) — thema met uitgebreide opmaakopties
- [GitHub Actions](https://docs.github.com/en/actions) — CI/CD voor automatische deployment
- [GitHub Pages](https://pages.github.com/) — gratis hosting van statische sites
