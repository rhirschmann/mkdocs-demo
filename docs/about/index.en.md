# About this project

This project demonstrates how easy it is to publish professional documentation
with **MkDocs** and **GitHub Actions** — fully automated and free of charge.

## What does this demo contain?

This demo has been progressively expanded with the following pages and components.

| Page / Component                | Description                                                   |
|---------------------------------|---------------------------------------------------------------|
| `index.md`                      | Welcome page with feature overview and navigation cards       |
| `features.md`                   | Extensive demonstration of 13 MkDocs Material features        |
| `getting-started/index.md`      | Introduction, project structure and how MkDocs works          |
| `getting-started/install.md`    | Installation instructions for local use                       |
| `getting-started/deployment.md` | Deployment to 7 different hosting platforms                   |
| `getting-started/alternatieven.md` | Comparison with 9 alternative documentation tools          |
| `about/index.md`                | Project information and technologies used                     |
| `blog/`                         | Blog functionality via the built-in Material blog plugin      |
| `changelog.md`                  | Version history of the project                                |
| `tags.md`                       | Overview page of all tags used                                |
| `includes/abbreviations.md`     | 24 abbreviations with official and etymological explanations  |

## Technologies used

- [MkDocs](https://www.mkdocs.org/) — static site generator for documentation
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) — theme with extensive formatting options
- [GitHub Actions](https://docs.github.com/en/actions) — CI/CD for automatic deployment
- [GitHub Pages](https://pages.github.com/) — free hosting for static sites
