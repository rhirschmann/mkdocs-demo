    Features

    Deze pagina demonstreert de belangrijkste features van MkDocs met het Material-thema. Gebruik deze pagina als referentie voor wat mogelijk is binnen je documentatieomgeving.

    404-pagina

    MkDocs genereert automatisch een 404-pagina die getoond wordt wanneer een bezoeker een niet-bestaande URL bezoekt. Bekijk hieronder hoe deze standaard foutpagina eruitziet.

    Bekijk de 404-pagina

    Tags

    Tags worden bovenaan de pagina getoond en maken het eenvoudig om pagina's te categoriseren en terug te vinden via de tagpagina. Voeg tags toe via de frontmatter bovenaan een Markdown-bestand:

    ---
tags:
  - demo
  - features
  - overzicht
---

    Admonitions

    Admonitions zijn gekleurde blokken om de lezer te attenderen op belangrijke informatie. MkDocs Material ondersteunt meerdere typen.

    Opmerking

    Dit is een informatieve opmerking, handig voor aanvullende uitleg.

    Tip

    Gebruik tips om de lezer te wijzen op handige trucs of shortcuts.

    Let op

    Gebruik dit blok om de lezer te waarschuwen voor mogelijke valkuilen.

    Gevaar

    Dit blok is bedoeld voor kritieke meldingen die directe aandacht vereisen.

    Succes

    Gebruik dit om een succesvol resultaat of een positieve bevestiging te tonen.

    Informatie

    Extra achtergrondinformatie die niet direct noodzakelijk is, maar nuttig kan zijn.

    Uitklapbaar voorbeeld (klik om te openen)

    Dit is een collapsible admonition. De inhoud is standaard verborgen en kan worden uitgeklapt door op de titel te klikken.

    echo "Hallo vanuit Bash!"

    Write-Host "Hallo vanuit PowerShell!"

    Grids & Cards

    Cards bieden een visuele manier om features of onderwerpen overzichtelijk te presenteren.

    • Snel opgezet

      Binnen enkele minuten een professionele documentatiesite draaien met MkDocs en het Material-thema.

    • Markdown

      Schrijf documentatie in eenvoudige Markdown-syntax, zonder kennis van HTML of CSS.

    • Zoekfunctie

      Ingebouwde zoekfunctie doorzoekt alle pagina's direct in de browser, zonder externe diensten.

    • Thema & Stijlen

      Pas kleuren, lettertypen en de lay-out volledig aan via de mkdocs.yml configuratie.

    Knoppen

    MkDocs Material ondersteunt gestylede knoppen via CSS-klassen. Knoppen kunnen worden gebruikt als call-to-action of voor navigatie.

    Afkortingen (Abbreviations)

    Door gebruik te maken van het includes/abbreviations.md bestand worden afkortingen automatisch voorzien van een tooltip. Beweeg je muis over de onderstaande afkortingen om de uitleg te zien.

    Deze documentatie is gebouwd met MkDocs en maakt gebruik van YAML voor de configuratie. De HTML-output wordt gegenereerd via een CLI-commando.

    Mermaid Diagrammen

    Met Mermaid kun je diagrammen en flowcharts schrijven in Markdown. Onderstaande voorbeelden laten verschillende diagramtypen zien.

    Takenlijsten

    Takenlijsten zijn handig om stappen of checklists overzichtelijk weer te geven. Met de tasklist extensie worden de checkboxen visueel gestijld.

    • MkDocs installeren
    • Material-thema instellen
    • Navigatie configureren
    • Features pagina aanmaken
    • Documentatie uitschrijven
    • Publiceren naar GitHub Pages

    Tabellen

    Tabellen worden volledig ondersteund in Markdown en zijn eenvoudig leesbaar en uitbreidbaar.

    Feature Beschikbaar Notitie
    Tags ✅ Via material/tags plugin
    Mermaid diagrammen ✅ Via pymdownx.superfences
    Zoekfunctie ✅ Ingebouwd, geen plugin nodig
    Content Tabs ✅ Via pymdownx.tabbed
    Admonitions ✅ Via admonition extensie
    Afkortingen ✅ Via abbr + snippets
    Knoppen ✅ Via attr_list extensie
    Footnotes ✅ Via footnotes extensie
    Grids & Cards ✅ Via md_in_html + CSS klassen
    Versiebeheer ⚙️ Via mike plugin (optioneel)
